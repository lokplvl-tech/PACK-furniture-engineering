# Bounded Context: Мебельный инжиниринг (Furniture Engineering)

---

## Domain Name

**Мебельный инжиниринг**

(English: Furniture Engineering)

---

## Object of Description

**Корпусный мебельный гарнитур** (кухня, шкаф, пенал) как объект инженерного описания в CAD-системах семейства «Базис».

| Object IS | Object IS NOT |
|-----------|---------------|
| Собранный физический холон L3 в конкретном помещении клиента | Абстрактный каталожный образец |
| Носитель измеримых атрибутов (габариты, зазоры, нагрузка фурнитуры) | Дизайнерская иллюстрация/рендер сам по себе |
| Экземпляр типа (нижний/верхний модуль, пенал, метровик) | Уникальное произведение искусства без инвариантов |

---

## Scope (What's In)

| Element | Description | Example |
|---------|-------------|---------|
| **Холархия L0-L6** | Уровни от физико-химического субстрата (L0) до инфраструктуры здания (L6) | уровни, например: ЛДСП/МДФ (L0) · деталь после конвейера (L1) · модуль (L2) · собранный гарнитур (L3) · помещение (L4) · квартирная разводка (L5) · стояки и магистрали здания (L6). Отношение состава - в [02F-holarchy.md](../02-domain-entities/02F-holarchy.md), здесь только перечень |
| **Роли конвейера** | Дизайнер-конструктор, Технолог, Монтажник, Фабрика, Клиент | Спецификация ролей (§2 источника) |
| **Гварды (Guards)** | Эпистемологические барьеры против локальных оптимизаций дизайнера в ущерб физике | Запрет сокрытия газовых магистралей за фальш-панелью |
| **Деонтика (MUST/MUST NOT)** | Жёсткие алгоритмические инварианты производства | ПВШ только в ящике 120 мм под духовым шкафом |
| **Технические справочники** | Допуски, зазоры, формулы расчёта полок и погонажа | Зазор от стены 41/51 мм; формула ширины полки |

---

## Non-Goals (What's Out)

| Excluded | Reason | Where It Belongs |
|----------|--------|------------------|
| Мягкая мебель (обивка, диваны) | Другая физика материалов и производство | Отдельный домен, вне этого Pack |
| Столярное искусство ручной работы | Не CAD-конвейер, другие роли и артефакты | Отдельный домен |
| Дизайн интерьера в целом (цвет, стиль, декор без инженерных инвариантов) | Эстетика без физических инвариантов - не предмет FPF-строгости | Смежный, но не этот Pack |
| Юридический/финансовый контур предприятия (ООО, бухгалтерия) | Governance, не предметное знание | DS-strategy |
| Планы и реестры конкретных РП мастерской | Учёт и планирование, не домен | DS-strategy/governance |

## Truth Criteria

Assertions in this pack are considered justified if:

| Criterion | Test |
|----------|------|
| **Observable indicators** | Числовой инвариант (зазор, нагрузка, допуск) проверяем измерением на объекте |
| **Verifiable work products** | Спецификация/Эскиз/Договор существуют как подписанные артефакты |
| **Distinction test** | Различение Объект/Описание/Спецификация проходит тест FPF A.7 |
| **SoTA + revision criterion** | Источник - корпоративный стандарт ESP_v2 (см. 06-sota/) |

**Forbidden**:
- Assertions without observable indicators
- Methods without work products
- SoTA without revision criterion
