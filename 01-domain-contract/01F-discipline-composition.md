# Композиция дисциплины: мебельный инжиниринг

> Оформлено по паттерну FPF `C.20` (Composition of `U.Discipline`, Discipline-CAL).

---

## 1. Вид дисциплины

**`U.AppliedDiscipline`** - зрелая прикладная инженерная дисциплина. Признаки бесспорны: устоявшийся производственный конвейер с шестью формализованными ролями, промышленный CAD-стек («Базис»), нормируемые физические инварианты (зазоры, нагрузка, допуски), два независимых источника (внутренний стандарт компании + отраслевой playbook), кросс-валидация между ними. Не трансдисциплина - методология привязана к конкретному классу изделий (корпусная мебель) и конкретному инструментальному стеку, не переносится на мягкую мебель или столярное искусство без переработки границ.

---

## 2. Носители практики

| Роль (`02A-roles.md`) | Функциональное место | Что производит |
|---|---|---|
| Дизайнер-конструктор (FE.R.001) | Транслирует физику изделия в CAD-модель (метод P2W, FE.M.001) | CAD-модель, эскиз |
| Технолог (FE.R.002) | Гейт на позиции 8 метода FE.M.001 - проверка перед производством | Утверждённая спецификация к производству |
| Монтажник | Установка изделия на объекте клиента | Смонтированный гарнитур |
| Фабрика (конвейер, FE.M.002) | Физическое производство модулей | Готовые модули |
| Клиент | Формулирует требование, принимает результат | Подписанный договор, приёмка |
| Менеджер (FE.R.006, из второго источника) | Расчёт погонажа и координация (FE.M.003) | Расчёт материалов, координация заказа |

**Тест на реальность практики:** роль Технолога как отдельный гейт (не совмещённый с Дизайнером-конструктором) - прямое структурное решение против конкретного класса ошибок домена: гварды (`FE.GRD.001-010`) существуют именно потому, что дизайнер-конструктор, оптимизируя эстетику, систематически склонен нарушать физические инварианты (пример из `01A`: сокрытие газовой магистрали за фальш-панелью) - без независимого гейта эта роль сама себя не остановит.

## 3. Корпус знания

| Слой корпуса | Содержание | Состояние в этом Паке |
|---|---|---|
| Холархия изделия | L0 (физико-химический субстрат) → L6 (инфраструктура здания) | Собрано, 7 уровней, L1/L2 с полными инвариантами |
| Метод трансляции физики в CAD | P2W (FE.M.001) | Формализован по `E.18`/`E.18.2`/`E.18.3`, 10 гвардов привязаны к точным позициям |
| Метод производства | Конвейер Фабрики (FE.M.002) | Собрано |
| Метод расчёта | Погонаж (FE.M.003) | Кросс-валидирован |
| Разрешение коллизий | Цикл АДИ (FE.M.005) | **Гипотеза** - единственный источник, статус явно понижен |
| Технические справочники | 11 характеристик (допуски, зазоры, формулы) | Собрано, 5 из 11 кросс-валидированы дословно по двум источникам |
| Метод визуализации | Фотореалистичный показ изделия клиенту (FE.M.007, 05.08.2026) | Проверено по независимому источнику (встроенные рендереры В-Рэй/Циклес и экспорт OBJ - реальная функция Базис-Мебельщик, не предположение); путь для PRO100/SketchUp - по аналогии через универсальный 3D-формат, отдельно не подтверждён |

**Честно зафиксированный пробел:** пятый источник (курс «Базис-Мебельщик») ingested, но не кросс-валидирован - новые карточки из него намеренно не создавались, только сырой разбор с открытыми вопросами. Схема ДРАКОН для метода визуализации (FE.M.007) ещё не построена по формальной девятипозиционной нарративизации - пока только пронумерованный алгоритм в тексте карточки метода.

---

## 4. Стандарты и нормативная опора

Нет единого государственного стандарта уровня ГОСТ (в отличие от дорожного покрытия) - опора здесь корпоративная: внутренний стандарт «Датум Мебель» (первичный источник) плюс отраслевой playbook «ONEON Kitchen» (второй независимый источник, кросс-валидация). Опора зрелая там, где числа совпали дословно между источниками (5 из 11 характеристик), фрагментарная там, где остался единственный источник (метод FE.M.005).

## 5. Институты

| Институт | Роль в дисциплине |
|---|---|
| Производители САПР «Базис» (Базис-Салон, Базис-Мебельщик, Базис-Шкаф) | Держат инструментальный слой, на котором построена вся методология |
| Компании-практики (Датум Мебель, ONEON Kitchen) | Держат внутренние стандарты - основной источник корпуса знания |
| Производители фурнитуры и техники (духовые шкафы, направляющие) | Держат физические ограничения (нагрузка ПВШ, размеры техники), которые становятся гвардами |

**Смещение источника, найденное независимой проверкой:** прогон по `E.4.DPF.DA` (вердикт `CONDITIONAL`) нашёл и исправил реальный дрейф - расхождение числа нагрузки ПВШ (15-20 vs 20 кг в разных карточках) и путаницу кода «Datum» (компания vs паттерн). Это подтверждает то же наблюдение, что и в других Паках этой сессии: без независимой поправки локальные несостыковки источников накапливаются незаметно.

## 6. Оценка состояния дисциплины (Γ_disc, качественно)

| Ось | Оценка | Комментарий |
|---|---|---|
| Воспроизводимость | высокая | Два независимых источника кросс-валидированы, числа совпадают дословно там, где оба высказались |
| Стандартизация | средняя | Есть корпоративные стандарты, нет единого отраслевого/государственного |
| Согласованность источников | высокая там, где кросс-валидировано; открытая там, где нет | 8/10 гвардов и 5/11 характеристик подтверждены дважды; остальное - единственный источник, статус понижен явно |
| Наличие независимой проверки | сильное | Формальный прогон по `E.4.DPF.DA` независимым ревьюером - редкий случай в этой системе, когда домен прошёл не только внутреннюю, но и внешнюю проверку адекватности |

**Следствие для практики:** это самый зрелый Пак из всех - единственный, где применена полная характеристика адекватности пакета (`E.4.DPF.DA`, 9 координат) и независимая проверка нашла и закрыла реальные ошибки. Остальным Пакам эта проверка ещё предстоит, если пилот сочтёт нужным довести их до того же уровня зрелости.

---

## 7. Граница дисциплины

Дисциплина заканчивается там, где начинается мягкая мебель, столярное искусство ручной работы, дизайн интерьера без инженерных инвариантов, либо юридический/финансовый контур предприятия - все явно исключены в `01A-bounded-context.md`.

Тест границы: «У этого элемента есть физический инвариант (нагрузка, зазор, допуск), который CAD-конвейер обязан соблюдать?» Есть - эта дисциплина. Только эстетика/декор без инварианта - смежный домен, вне Пака.
