## What is a Tool?

Per FPF: A **tool** is an artifact (physical or digital) that enables or facilitates the performance of a method. Tools are used; methods are performed.

A tool is NOT:
- A method (tools support methods)
- A work product (work products are outputs; tools are enablers)
- A skill (skills are in the agent; tools are external)

## Tool Entry Format (Detailed)

### «Базис» — семейство инструментов (Базис-Салон, Базис-Мебельщик, Базис-Шкаф и др.)

**Type**: software

**Purpose**: Точка входа для метода [FE.M.001](../03-methods/FE.M.001.md) — построение изоморфной цифровой модели гарнитура и генерация Спецификации.

Не одна программа: конкретный инструмент семейства зависит от типа изделия и шага (например, шкафы/пеналы могут вестись в «Базис-Мебельщик»/«Базис-Шкаф», кухонный гарнитур целиком — в «Базис-Салон»); все 8 шагов P2W выполняются внутри этого семейства.

**Supports methods**:
- [FE.M.001](../03-methods/FE.M.001.md)

**Alternatives**: _не документированы — стандарт предприятия «Датум Мебель» жёстко привязан к этому семейству САПР_

**Notes**: Пилот работает с собственным форком инструментов семейства «Базис». Расхождения форка с описанным в источнике поведением — фиксировать как отдельное различение, если найдутся.

Точное соответствие «какой шаг метода — в каком конкретно инструменте семейства» не размечено — кандидат на уточнение при следующей проверке пилотом.

## Notes on Tool Documentation

- Раскрой / ЧПУ / Смета / Склад / Салон / Упаковка / Менеджер прайс-листов образуют отдельный, ещё не формализованный конвейер (кандидат метода FE.M.002 — физическая сборка L0→L1, роль [FE.R.005](02A-roles.md#fe-r-005) Фабрика)
- Семейство «Базис» (Базис-Салон, Базис-Мебельщик, Базис-Шкаф и др.) закрывает весь метод FE.M.001, но не как единая программа — набор связанных инструментов одного вендора; остальные модули (Раскрой/ЧПУ/Смета/…) относятся к работам ПОСЛЕ шага 8 (DRR и Комиссионирование)
