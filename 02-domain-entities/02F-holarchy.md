# Holarchy (HOL): Мебельный инжиниринг

> Extended kind `HOL` (см. `ontology.md` §1, `00-pack-manifest.md` Extended Kinds). Источник: `06-sota/Эпистемологический стандарт предприятия.md` §1 «Целевая система бизнеса и физические границы (Холархия L0-L6)», термин введён Артуром Кестлером (1967). Холон — объект, одновременно автономное целое на своём уровне и зависимая деталь системы более высокого макроуровня.
>
> По приоритету «Наполнение L1/L2» (2026-07-26): L0, L3-L6 оформлены кратко (структурный каркас), L1 и L2 — подробно, с полными инвариантами и кросс-ссылками.

## [FE.HOL.L6] Инфраструктура здания

**Definition**: Магистральные сети здания — центральный газопровод, стояки водоснабжения, фановые трубы центральной канализации, магистральные электросети, стационарные вентиляционные шахты.

**Границы**: Полностью за пределами Work Scope любого агента предприятия ([FE.D.003](../01-domain-contract/01B-distinctions.md#fe-d-003)). Задаёт абсолютные физические инварианты, запрет на пересечения материи гарнитура с магистралями.

**Composes →**: содержит L5 (квартирная разводка подключается к магистралям L6)

**Related Guards**: [FE.GRD.002](../05-failure-modes/FE.GRD.002.md) (сокрытие газовых коммуникаций — прямое нарушение границы L6)

---

## [FE.HOL.L5] Квартирная разводка

**Definition**: Внутриквартирные выводы инженерных сетей — водорозетки, локальные точки электропитания, гофры вытяжной вентиляции.

**Границы**: Требует обязательного физического аудита интерфейсов. Топология выводов L5 диктует расположение «мокрых зон» и «зон нагрева». **Данные L5 истинны исключительно на момент подписания акта замера** — временная метка, не постоянный факт.

**Composes →**: подключается к L6, определяет ограничения для L2 (положение мойки/техники относительно розеток и труб)

**Related Guards**: [FE.GRD.005](../05-failure-modes/FE.GRD.005.md) (ПММ дальше 1200 мм от мойки — нарушение топологии L5)

---

## [FE.HOL.L4] Помещение

**Definition**: Физические границы жилой комнаты — капитальные стены, перегородки, пол, потолок.

**Границы**: Задаёт топологию пустот, оперирует понятием «Габарит». Углы схождения плоскостей никогда не равны идеальным 90°. **Истинно исключительно на момент замера на трёх высотных уровнях.**

**Composes →**: содержит L2 (модули расставляются внутри границ L4), фиксируется на шаге 1 метода [FE.M.001](../03-methods/FE.M.001.md) как Claim Scope

**Related Distinctions**: [FE.D.003](../01-domain-contract/01B-distinctions.md#fe-d-003) Work Scope vs Claim Scope

---

## [FE.HOL.L3] Собранный кухонный гарнитур (целевой холон)

**Definition**: Агрегированный киберфизический холон (TargetSlice) в квартире клиента — финальная точка приложения усилий предприятия, конечный результат материализации информации из семейства САПР «Базис» в физическую материю.

**Границы**: Зона ответственности Монтажника (Work Scope). Собирается из холонов L2 на объекте у клиента.

**Composes →**: агрегирует L2 (модули) в единую систему; сам является частью L4 (помещения)

**Related Roles**: [FE.R.003](02A-roles.md#fe-r-003) Монтажник

**Related Methods**: [FE.M.006](../03-methods/FE.M.006.md) — монтаж, производящий этот холон из L1+L2

## [FE.HOL.L2] Подсистемы (Модули)

**Definition**: Крупные сборочные единицы, выступающие ролями внутри гарнитура L3. Пять типов, каждый — отдельный холон со своей функцией:

| Тип модуля | Функция | Ключевой инвариант |
|------------|---------|----------------------|
| Нижние модули корпуса | Задают базовую горизонтальную ось (Datum) | Расстановка **всегда** первый шаг построения проекта ([FE.M.001](../03-methods/FE.M.001.md) шаг 2a); угловые кухни строят от угла |
| Верхние модули | Гравитационно независимое хранение | Симметрия вертикальных линий с нижним ярусом (шаг 5 FE.M.001); уровень навески 1420 мм (ножки 100) / 1470 мм (ножки 150) |
| Пеналы | Шкафы-колонны под встраиваемую технику | Высота пенала зависит от высоты верхних модулей: 720→2140/2190, 920→2340/2390; глубина по корпусу с ручкой 604 мм |
| Угловой модуль (Метровик) | Особый L-образный холон, обход угла | Считается по обеим сторонам прилегания к стене при расчёте погонажа ([FE.M.003](../03-methods/FE.M.003.md)) — например 1000+600 мм |
| Кинематика интегрированных фасадов | Траектории движения (петли, газлифты, выдвижение) | Тип механизма жёстко завязан на тип и массу фасада — см. [FE.GRD.004](../05-failure-modes/FE.GRD.004.md) |

**Границы**: Дизайнер-конструктор расставляет ([FE.M.001](../03-methods/FE.M.001.md) шаги 2a-7), Фабрика изготавливает детали для сборки модулей (см. [FE.HOL.L1](#fe-hol-l1)).

**Composes →**: собирается из деталей L1, агрегируется в L3

**Часто путают**: Модуль (L2, холон-подсистема, устойчивая функциональная единица) vs Холон (L2 — родовое понятие уровня; конкретный модуль — экземпляр холона на этом уровне). См. [FE.D.008](../01-domain-contract/01B-distinctions.md#fe-d-008) Холон vs Модуль.

**Related Methods**: [FE.M.001](../03-methods/FE.M.001.md) (расстановка), [FE.M.003](../03-methods/FE.M.003.md) (расчёт погонажа по модулям)

**Related Guards**: [FE.GRD.001](../05-failure-modes/FE.GRD.001.md) (зазоры между модулями), [FE.GRD.004](../05-failure-modes/FE.GRD.004.md), [FE.GRD.007](../05-failure-modes/FE.GRD.007.md) (несовместимость фурнитуры/техники с конкретным модулем)

## [FE.HOL.L1] Атомарные детали и конвейер

**Definition**: Физические детали и номенклатура — базовые единицы складского учёта. Физическое воплощение информации из САПР подчиняется строгим аппаратным инвариантам производственного конвейера Фабрики: пять последовательных стадий (раскрой → кромление → присадка → ПВХ-плёнка → комплектование) превращают субстрат L0 в готовые детали для сборки модулей L2. Полная таблица стадий с инвариантами и контрфактикой — каноническая версия в карточке метода [FE.M.002](../03-methods/FE.M.002.md).

**Границы**: Работа Фабрики (Work Scope). Электронная Спецификация из семейства «Базис» — абсолютная истина для станков конвейера; Фабрика не исправляет ошибки дизайна.

**Composes →**: производится из субстрата L0, собирается в модули L2

**Кросс-валидировано** источником ONEON Kitchen дословно — идентичные числа (скорость резки 80 м/с, погрешность присадки, нагрев плёнки 160°C) в `06-sota/oneon-kitchen-tehchast.md` §1. Отраслевой стандарт, не идиосинкразия одной компании.

**Related Roles**: [FE.R.005](02A-roles.md#fe-r-005) Фабрика

**Related Methods**: [FE.M.002](../03-methods/FE.M.002.md) — метод физической сборки L0→L1, оформлен по этой же таблице

## [FE.HOL.L0] Физико-химический базис

**Definition**: Фундаментальный физико-химический субстрат — ЛДСП, МДФ, HPL-пластик, столешница (постформинг), плёнка ПВХ. Игнорирование параметров уровня L0 неизбежно разрушает макроуровни. Станки с ЧПУ работают с информационными абстракциями, но режут физическую материю.

**Границы**: Не проектируется — задан свойствами закупленного материала. Полная таблица материалов и их физических ограничений — `06-sota/Эпистемологический стандарт предприятия.md` §1 (Таблица «Материальный уровень L0»), базовый словарь терминов — там же и в `06-sota/oneon-kitchen-tehchast.md` §2.

**Composes →**: сырьё для L1 (детали конвейера)

**Related Distinctions**: [FE.D.007](../01-domain-contract/01B-distinctions.md#fe-d-007) Тандембокс vs ПВШ (различение на уровне готовой фурнитуры, но зависит от несущей способности субстрата L0)
