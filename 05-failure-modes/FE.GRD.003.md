## [FE.GRD.003] Назначение HPL-пластика на фрезерованный фасад

### Definition

Дизайнер назначает материал HPL-пластик (AGT) на фасад с параметрической лекальной 3D-фрезеровкой, хотя материал термореактивен и не облегает рельеф.

### Category

**This failure mode is**: `method-failure` — нарушение на шаге 7 метода [FE.M.001](../03-methods/FE.M.001.md) (замена фасадов и цвета).

### Observable Symptoms

- [ ] В спецификации на фрезерованный фасад назначен пластик HPL/AGT вместо МДФ с плёнкой/эмалью
- [ ] Клиенту предложена экономия за счёт замены материала без учёта совместимости с формой фасада

### Root Causes

| Cause | Description |
|-------|-------------|
| Удешевление проекта | HPL дешевле альтернатив, соблазн назначить его на любой фасад |
| Незнание физики материала | Термореактивный монолит не эластичен, не может обволакивать 3D-рельеф |

### Consequences

- Физическая невозможность нанесения материала на фрезерованную поверхность на производстве
- Остановка производства партии, пересогласование с клиентом

HPL-пластик — ТОЛЬКО на гладкие прямые МДФ-фасады. Роль-контролёр: Технолог. Артефакт-доказательство: Спецификация из семейства «Базис».
