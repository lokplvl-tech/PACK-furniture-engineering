## [FE.GRD.006] Расчёт встроенной техники «на глаз» без артикула

### Definition

Дизайнер проектирует пенал или модуль под встраиваемую технику (холодильник, СВЧ, духовой шкаф), опираясь на усреднённые размеры вместо точного артикула конкретной модели клиента.

### Category

**This failure mode is**: `method-failure` — нарушение на шаге 4 метода [FE.M.001](../03-methods/FE.M.001.md) (интеграция бытовой техники).

### Observable Symptoms

- [ ] В заказе указан только тип техники («холодильник встроенный»), без артикула
- [ ] Фасад пенала рассчитан по «стандартным» размерам без проверки конкретной модели

### Root Causes

| Cause | Description |
|-------|-------------|
| Дефицит информации от клиента на момент проектирования | Клиент ещё не выбрал конкретную модель техники |
| Спешка на этапе презентации | На шаге 4 техника ставится «для презентации», легко забыть уточнить артикул до продажи |

### Consequences

- Фасад пенала не подходит по факту к купленной клиентом технике
- Пересогласование и повторное изготовление фасада за счёт компании

### Guard (блокирующий инвариант)

Размер фасада встраиваемой техники рассчитывается исключительно Технологом по конкретному артикулу модели. Роль-контролёр: Технолог. Артефакт-доказательство: метка в Базис-Салон с артикулом.

### Detection Methods

| Detection Method | When to Apply |
|--------------------|----------------|
| Проверка наличия артикула перед расчётом фасада | Шаг 8 FE.M.001, до передачи в производство |

### Notes

**Кросс-валидировано** источником ONEON Kitchen: для встроенных СВЧ, холодильника, стиральной машины и ПММ фасад «рассчитывает технический отдел» строго по артикулу — идентичный принцип (`06-sota/oneon-kitchen-tehchast.md` §6). Дополнительно в 41-точечном чек-листе ONEON пункт 22: «Расчет фасада для встроенного холодильника и встроенной СВЧ делает технический отдел по артикулу».
