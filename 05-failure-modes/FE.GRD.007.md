## [FE.GRD.007] Отдельно стоящая стиральная машина за профилем GOLA

### Definition

Дизайнер назначает алюминиевый профиль GOLA (скрытая ручка, врезаемая в корпус модуля) на модуль, соседствующий с отдельно стоящей стиральной машиной, хотя профиль физически врезается в стенки деревянных модулей и несовместим с отдельной техникой.

### Category

**This failure mode is**: `method-failure` — нарушение на шаге 7 метода [FE.M.001](../03-methods/FE.M.001.md) (замена фасадов и фурнитуры).

### Observable Symptoms

- [ ] В проекте одновременно присутствуют профиль GOLA и отдельно стоящая СМ
- [ ] В спецификации не указан тип стиральной машины (встроенная/отдельная) рядом с GOLA-модулями

### Root Causes

| Cause | Description |
|-------|-------------|
| Единый стиль ручек по всей кухне | Клиент хочет сквозной GOLA-профиль без учёта техники |
| Незнание конструктивного ограничения профиля | GOLA — это врезка в корпус, а не накладная деталь |

### Consequences

- Невозможность физической установки профиля рядом с отдельной СМ, брак проекта

### Guard (блокирующий инвариант)

GOLA-профиль несовместим с отдельно стоящей стиральной машиной. Роль-контролёр: Технолог. Артефакт-доказательство: спецификация с явно указанным типом стиральной машины.
