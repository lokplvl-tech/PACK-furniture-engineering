# Kitchen Systems Engineering — визуальный плейбук (синтезированный источник)

> Источник: `Kitchen_Systems_Engineering.pdf` (v1.3, «для дизайнеров-конструкторов», помечен «Конфиденциально»). Судя по водяному знаку — сгенерирован инструментом NotebookLM, вероятно на основе тех же материалов «Датум Мебель»/ONEON. Это **не первичный источник компании**, а синтезированное производное — обращаться с осторожностью: числа перепроверены против уже ingested источников (совпадают), но сама рамка (Tension Triangle, Nested Node, Alpha-прогрессия) — интерпретация третьей стороны/инструмента, не документ предприятия.
> Ingested: 2026-07-26. Статус: сырой ingested-материал (Stage 05).

## Что подтверждает уже известное (кросс-валидация)

- Холархия L1-L6 (Material → Component → Module → Space → Living environment → Infrastructure) — дословно совпадает со структурой `02F-holarchy.md`.
- Гарантийный контур (24 мес. материалы / 1 год сборка / 5 лет Blum-Hettich) — совпадает с [FE.SC.001](../08-service-clauses/FE.SC.001.md).
- Supply chain (лид → проект → производство 14-30 дней → склад Подольск → доставка раз в неделю по воскресеньям → сборка 10% от базы) — совпадает с §13.1 источника ONEON.
- Матрица покрытий (Decoline/AGT/Эмаль) и запрет AGT под фрезеровку — совпадает с §13.2.

## Что действительно новое

1. **Явный запрет бренда Кроношпан** для корпуса (запрет, не просто «не упомянут») — стандарт корпуса: Увадрев (эмиссия 0.5) или Egger.
2. **Инженерное обоснование фрезеровки:** МДФ можно фрезеровать, а ЛДСП нельзя — потому что у МДФ однородная структура (нет слоёв стружки/плёнки, которые фрезеровка вскрывает). Ранее в паке это было только правилом, без обоснования "почему".
3. **ПВШ (полно-выкатные направляющие) — только для гардеробных, НЕ для кухонь.** Для кухонных ящиков — строго направляющие скрытого монтажа под дно ящика (ДСП-дно, не ХДФ-дно). Это уточнение, отсутствовавшее в [FE.CHR.006](../02-domain-entities/02E-characteristics-registry.md#fe-chr-006) (там только нагрузка «до 20 кг» без разделения по типу мебели).
4. **Пожароопасность отдельно стоящей техники в закрытом пенале — строгий запрет**, не просто эстетическое неудобство: нарушение конвекции и теплообмена ведёт к поломке компрессора и **высокой пожароопасности**. Встраиваемая техника допустима — спроектирована с учётом теплоотвода внутри короба.
5. **Алюминиевая планка для стыка столешниц — устаревшее решение** (образует микро-порог, влага проникает в ДСП-основу через щели); еврозапил явно предпочтителен и описан точнее: замковое фрезерование + скрытые стяжки + герметик в тон.
6. **Правило интерфейса для разнородных материалов:** при стыке принципиально разных материалов (например, кафель стены и столешница) — использовать ТОЛЬКО герметик, чтобы компенсировать разное температурное расширение. Общее правило, не привязанное к одному узлу.
7. **Антресоли — точный физический порог:** оптимальная высота потолка для трёхуровневых антресолей ≥2600 мм; если ниже — заменять на двухуровневую систему «шкафы в потолок» с увеличением стандарта фасада с 920 до 1100 мм.
8. **Фрезеровка — точная толщина:** фасад под фрезеровку строго 18 мм (лекало «съедает» 2 мм глубины); покрытие только плёнка ПВХ или эмаль, пластик AGT — запрет (согласуется с п.2 выше).
9. **Деонтические нормы уровня всего предприятия** (не одного узла): MUST всегда заключать официальный договор с подробной спецификацией; MUST NOT обещать клиенту «инструкцию по сборке» (мебель кастомная, собирается только профессионалами); MUST NOT менять цену после подписания договора без фиксации изменения пожеланий клиента.

## Alpha-прогрессия для роли Дизайнера-конструктора (кандидат метода обучения)

Пятиступенчатая модель мастерства, использующая рамку OMG Essence (Alpha-progression) — совпадает с моделью из `fpf_analysis_designer.pdf` (см. [[WP-7]]):

| Ступень | Название | Описание |
|---|---|---|
| Alpha 1 | Новичок | Отличает опилки от волокон (ЛДСП vs МДФ) |
| Alpha 2 | Проектировщик | Собирает правильную матрицу совместимости «Покрытие + Ручка» |
| Alpha 3 | Инженер | Управляет физикой помещения (вентиляция пеналов, расчёт высоты антресолей) |
| Alpha 4 | Автономный | Выпускает спецификации без возвратов и правок от технолога |
| Alpha 5 | Эталон | Формирует новые граничные нормы сам |

**Не перенесено в формальную карточку метода в этой итерации** — кандидат на FE.M.004 (обучение роли Дизайнера) при следующем цикле, вместе с материалом `fpf_analysis_designer.pdf`.

## Жизненный цикл производства (9 шагов, детализация)

Лид → Замер (угроза: неровности стен/пола, замер на нескольких уровнях высоты обязателен) → 3D-проект (дизайнер выступает «владельцем требований» между желаниями клиента и физикой материалов) → Договор (цена фиксируется намертво, юридическая гарантия 24 мес.) → **Передача Технологу** → Производство → Доставка → Сборка → Гарантия.

Явное выделение шага «Передача Технологу» между Договором и Производством согласуется с ролью [FE.R.002](../02-domain-entities/02A-roles.md) (контроль-гейт на шаге 8 FE.M.001).

## Что это НЕ даёт (честно)

Это синтез, не первичный источник — рамки (Tension Triangle, Nested Node, Alpha-прогрессия) стоит воспринимать как удобную визуализацию уже известного + несколько по-настоящему новых фактов (пп.1-9 выше), а не как новый независимый источник для кросс-валидации в духе SoTA Harvester (G.2). Числа, которые совпадают с ONEON/Датум — не третье независимое подтверждение, а тот же материал, пересказанный иначе.

## Дополнение из второй версии плейбука (`Kitchen_Systems_Engineering 2.pdf`, «Master Reference Guide»)

Тот же генератор, более развёрнутая версия (21 слайд вместо 15). Подтверждает всё выше плюс:

- **Разрешение открытого расхождения по ПВШ** (см. правку в [FE.CHR.006](../02-domain-entities/02E-characteristics-registry.md#fe-chr-006)): «телескопические шариковые (ПВШ) — для шкафов-купе, но в кухнях предпочтительны скрытые направляющие под дном ящика (эстетика и защита от влаги)». Не строгий запрет, а явное предпочтение — снимает вопрос.
- **Явный запрет двух конкретных брендов плёнки:** Адилет и Тадж (наравне с уже известным запретом Кроношпан для корпуса).
- **МДФ от Egger запрещён именно для фасада** (хотя Egger разрешён как поставщик ЛДСП для корпуса) — нюанс, не встречавшийся раньше: разные бренды одного поставщика допустимы на одном уровне холархии и запрещены на другом.
- **GOLA-профиль — алюминиевый профиль, встроенный в корпус, а не в фасад** (создаёт пространство для захвата пальцами) — точное уточнение конструкции.
- **Доводчики обязательны везде** («петли исключительно с доводчиками») — обоснование: гасят кинетическую энергию, хлопки дверью расшатывают крепёж, разрушают геометрию петель, приводят к сколам эмали/стекла.
- **Выпилы под коммуникации (мойка, варочная) в столешнице оплачиваются отдельно от базовой сборки (10%)** — новая деталь ценообразования.
- Чистая сводка деонтики уровня предприятия в формате MUST / SHALL (рекомендуется) / MUST NOT — включает всё найденное выше одним списком.
