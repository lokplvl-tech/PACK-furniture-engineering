# PACK-furniture-engineering

Source-of-truth для домена: инженерная методология проектирования и производства корпусной мебели на базе САПР «Базис-Салон».
Структура: SPF/pack-template. Upstream: FPF, SPF.

**Источник затравочного документа (06-sota/):** внутренний стандарт компании «Датум Мебель» - её собственная методология, не гипотетический пример. Компания фигурирует в DS-strategy как РП-7 («Датум Мебель - первый шаг»). Важно не путать: этот Pack - про домен (мебельный инжиниринг в целом), «Датум Мебель» - один конкретный источник и одна конкретная компания внутри домена. Название Pack'а компанией не заменять.

При работе с этим Pack: читать 00-pack-manifest.md для навигации.

Имя финализировано (`name_status: finalized`, код `FE`). Новые различения в `01-domain-contract/01B-distinctions.md` получают заголовок `### FE.D.NNN: <Название>`.
