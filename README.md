# PACK-furniture-engineering

Инженерная методология проектирования и производства корпусной мебели (кухонные гарнитуры, шкафы, пеналы) на базе семейства САПР «Базис» (Базис-Салон, Базис-Мебельщик, Базис-Шкаф и др.), построенная в парадигме FPF (First Principles Framework).
